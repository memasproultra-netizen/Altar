# Altar Admin (NeoForge 1.21.1)

Мод для RP-сервера: алтарь с подношениями, админ-GUI, просмотр/правка инвентарей, вечные эффекты.

## Что умеет

- **Блок «Алтарь»** (вкладка «Функциональные блоки»). В выживании неразрушим, ломается только в креативе.
  - ПКМ с нужным предметом — принести подношение (считается общий прогресс).
  - ПКМ пустой рукой — посмотреть, что требует алтарь и сколько уже принесено.
- **Админ-GUI** (клавиша **K** или `/altaradmin`), только для операторов (уровень 2+):
  - Любой предмет по id, в т.ч. из других модов (`modid:item`), и количество. «Предмет из руки» подставляет id сама.
  - «Объявить всем» рассылает всем игрокам список, что принести.
  - Просмотр и правка инвентаря игрока в сети (броня, вторая рука, инвентарь, хотбар).
  - Эффект навсегда (любой, в т.ч. модовый; уровень 0 = I). Возвращается после смерти, молока и перезахода. Снять можно только через панель.
- Все права проверяются на сервере.

## Как получить готовый jar

**Вариант А — на своём компьютере (Windows):**
1. Поставь JDK 21 (например, Temurin 21).
2. Распакуй архив, дважды кликни `build.bat`. Первая сборка скачивает Minecraft и NeoForge, это несколько минут.
3. Мод: `build/libs/altarmod-1.0.0.jar`.

(Linux/macOS: `./gradlew build`.)

**Вариант Б — без установки чего-либо, через GitHub:**
1. Создай пустой репозиторий на github.com и загрузи в него содержимое архива (Add file → Upload files).
2. Вкладка Actions → «Build mod» → Run workflow.
3. Когда сборка закончится, внизу страницы запуска скачай артефакт `altarmod-jar`.

## Установка

Положи jar в папку `mods` у сервера **и у каждого игрока**. Нужны NeoForge 21.1.x и Minecraft 1.21.1.
В игре: возьми блок «Алтарь» из креатива (вкладка «Функциональные блоки»), нажми **K** (оператор) или напиши `/altaradmin`.

## Права

`AdminActions.isAdmin` — сейчас `p.hasPermissions(2)`. Меняется одной строкой.
